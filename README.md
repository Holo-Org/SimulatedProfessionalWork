# MAXWELL

A tool for web developers: it reports the exact gzip cost of every source in their bundle, then
makes that bundle smaller while every existing decoder can still read it. Its engine is a DEFLATE
codec written from scratch in OCaml, compiled with OxCaml.

MAXWELL is an Epitech B-PRO-500 project (*Simulated Professional Work*).
